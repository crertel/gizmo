@@http-worker
Set up a web server on port 8080 serving a system status page. You run as
root in a NixOS VM.

USE NIXOS CONFIGURATION. Edit /etc/nixos/configuration.nix to enable nginx
and create a status page. Then run nixos-rebuild switch. Example additions:

  services.nginx.enable = true;
  services.nginx.virtualHosts."status" = {
    listen = [{ addr = "0.0.0.0"; port = 8080; }];
    root = "/var/www";
  };

Write an HTML status page to /var/www/index.html with system info (hostname,
kernel, uptime, disk, memory, network). nixos-rebuild will start nginx
automatically.

bash/batch/editor request, and return continuation frames that examine
the reply on the next cycle. Keep going until the service is configured
and verified.

  1. Send {"text": "PASS: web server on port 8080"} to 'human'.
  2. Send {"text": "HTTP_OK"} to ${_parent}.
  3. Terminate with empty frames [].

On failure, send error details to 'human' and retry. Don't give up.
@@end

@@mail-worker
Set up an SMTP server on port 25 that accepts and stores incoming email.
You run as root in a NixOS VM.

The host sends mail via:
  curl smtp://localhost:2525 --mail-from user@host --mail-rcpt root@gizmo-vm -T - <<< "Subject: hello"

USE NIXOS CONFIGURATION. Edit /etc/nixos/configuration.nix to enable postfix.
Then run nixos-rebuild switch. Example additions:

  services.postfix = {
    enable = true;
    hostname = "gizmo-vm";
    destination = [ "gizmo-vm" "localhost" ];
  };

nixos-rebuild will start postfix automatically. Mail goes to /var/mail/ or
/var/spool/mail/ depending on configuration.

MESSAGE-DRIVEN PATTERN: Each wake should do one step, send any needed
bash/batch/editor request, and return continuation frames that examine
the reply on the next cycle. Keep going until postfix is configured
and verified.

When verified (test email found in mail storage):
  1. Send {"text": "PASS: mail server on port 25"} to 'human'.
  2. Send {"text": "MAIL_OK: stored at <path>"} to ${_parent}.
  3. Terminate with empty frames [].

On failure, send error details to 'human' and retry. Don't give up.
@@end

@@dispatch

Batch results in ${_payload} as JSON with a "results" array.

Based on the progress file, decide what work remains. Dispatch phases

@@child-report
