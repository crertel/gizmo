You are a supervisor running a number-guessing game. You spawn a child
that rolls dice on a watchdog timer. If it rolls 1, kill it via reaper.
Otherwise the child keeps rolling whenever the watchdog wakes it.

Messages arrive as ${_msg} from ${_msg_source}. All messages are JSON
objects. The msg field in send ops must be a JSON object. This is the
first cycle (${_msg} is "init").
Any cycle that should survive to another wake MUST send {"text": "renew"} to 'keep_alive'.

@@roller
You are the roller child. Messages arrive as ${_msg} from ${_msg_source}.

If ${_msg} is "init":
  1. Send {"action": "every", "ms": 2000} to 'watchdog'.
  2. Send {"text": "renew"} to 'keep_alive'.
  3. Return frames: [].

If ${_msg_source} is "watchdog":
  1. Send {"command": "printf \"%d\" $(shuf -i 1-6 -n 1)"} to 'bash'.
  2. Send {"text": "renew"} to 'keep_alive'.
  3. Return frames: ["@1"].

Otherwise: return frames: [].
@@end

@@wait-roll
Waiting for the bash result. Message: ${_msg} from ${_msg_source}.

If ${_msg_source} is "bash":
  1. Send {"text": "rolled:${_msg}"} to ${_parent}.
  2. Send {"text": "Child: I rolled ${_msg}"} to 'human'.
  3. Send {"text": "renew"} to 'keep_alive'.
  4. Return frames: [].

Otherwise: send {"text": "renew"} to 'keep_alive' and return frames: ["@0"].
@@end

@@check-roll
A message arrived as ${_msg} from ${_msg_source}.

If ${_msg} starts with "rolled:":
  Send {"text": "Parent: child ${_msg}"} to 'human'.
  Extract the number after "rolled:".
  If it is "1":
    Send {"target": "${child}"} to 'reaper'.
    Send {"text": "renew"} to 'keep_alive'.
    Return frames: ["@wait-for-death"].
  Otherwise:
    Send {"text": "renew"} to 'keep_alive'.
    Return frames: ["@check-roll"].

If ${_msg_source} is "runtime" and ${_msg} starts with "child_died:":
  Send {"text": "Parent: child died! ${_msg}"} to 'human'.
  Terminate with empty frames [].

Otherwise: send {"text": "renew"} to 'keep_alive' and return frames: ["@check-roll"].
@@end

@@wait-for-death
The reaper was asked to kill the child. A message arrived as ${_msg}.
If ${_msg_source} is "runtime" and ${_msg} starts with "child_died:":
  Send {"text": "Parent: child was reaped! ${_msg}"} to 'human'.
  Terminate with empty frames [].
Otherwise: return frames: ["@wait-for-death"].
Also send {"text": "renew"} to 'keep_alive' when continuing to wait.
@@end

Step 1:
1. Send {"text": "Parent: spawning roller child..."} to 'human'.
2. Spawn a child with frames: ["@roller", "@wait-roll"], dest "child".
3. Send {"text": "renew"} to 'keep_alive'.
4. Return frames: ["@check-roll"].
