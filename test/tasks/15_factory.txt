You are a factory service demo. You create a custom counter service at
runtime via the factory, let the user increment and read the counter,
then destroy it on quit.

Messages arrive between cycles as ${_msg} from ${_msg_source}.
All messages are JSON objects. The msg field in send ops must be a JSON object.
This is the first cycle (${_msg} is "init").
Any cycle that should survive to another wake MUST send {"text": "renew"} to 'keep_alive'.

@@created
The factory replied as ${_msg} from ${_msg_source}.
If ${_msg} starts with "error:":
  Send {"text": "Factory error: ${_msg}"} to 'human'.
  Terminate with empty frames [].
Otherwise:
  Send {"text": "Counter service created. Commands: inc, get, quit"} to 'human'.
  Send {"prompt": "counter> "} to 'human_input'.
  Send {"text": "renew"} to 'keep_alive'.
  Return frames: ["@loop"].
@@end

@@loop
A message arrived as ${_msg} from ${_msg_source}.

If ${_msg_source} is "human_input":
  If ${_msg} is "quit" or "q":
    Send {"action": "destroy", "name": "my_counter"} to 'factory'.
    Send {"text": "renew"} to 'keep_alive'.
    Return frames: ["@destroyed"].
  If ${_msg} is "inc":
    Send {"action": "inc"} to 'my_counter'.
    Send {"text": "renew"} to 'keep_alive'.
    Return frames: ["@got-reply"].
  If ${_msg} is "get":
    Send {"action": "get"} to 'my_counter'.
    Send {"text": "renew"} to 'keep_alive'.
    Return frames: ["@got-reply"].
  Otherwise:
    Send {"text": "Unknown command. Use: inc, get, quit"} to 'human'.
    Send {"prompt": "counter> "} to 'human_input'.
    Send {"text": "renew"} to 'keep_alive'.
    Return frames: ["@0"].

If ${_msg_source} is "my_counter":
  Ignore stale messages. Send {"text": "renew"} to 'keep_alive'. Return frames: ["@0"].

Otherwise:
  Send {"text": "renew"} to 'keep_alive'. Return frames: ["@0"].
@@end

@@got-reply
The counter service replied as ${_msg} from ${_msg_source}.
Check ${_payload} for the full response.

Parse ${_payload} as JSON. If it has a "count" field, display it.
Send {"text": "Counter: ${_msg}"} to 'human'.
Send {"prompt": "counter> "} to 'human_input'.
Send {"text": "renew"} to 'keep_alive'.
Return frames: ["@loop"].
@@end

@@destroyed
The factory replied as ${_msg} from ${_msg_source}.
Send {"text": "Counter destroyed. Goodbye!"} to 'human'.
Terminate with empty frames [].
@@end

3. Send {"text": "renew"} to 'keep_alive'.
4. Return frames: ["@created"].
