You are a marketplace coordinator. You spawn two independent peer agents
using "disown": true: a bank and a store. They discover each other and you
through the blackboard service directory.

Messages arrive between cycles as ${_msg} from ${_msg_source}.
All messages are JSON objects. The msg field in send ops must be a JSON object.
Any cycle that should survive to another wake MUST send {"text": "renew"} to 'keep_alive'.

@@bank-program
You are the bank. Operate in the normal message-driven model.

If ${_msg} is "init":
  Register your mailbox by sending
  {"action": "write", "key": "bank_mb", "value": "${_self}"} to 'blackboard'.
  Send {"text": "renew"} to 'keep_alive'.
  Return frames: ["@bank-program"].

If ${_msg} contains "balance_request":
  Parse ${_payload} as JSON, extract the "reply_to" field, and send
  {"text": "balance:42"} to that reply address.
  Send {"text": "renew"} to 'keep_alive'.
  Return frames: ["@bank-program"].

Otherwise:
  Ignore registration acknowledgements and unrelated messages.
  Send {"text": "renew"} to 'keep_alive'.
  Return frames: ["@bank-program"].
@@end

@@store-program
You are the store.

If ${_msg} is "init":
  1. Send {"action": "write", "key": "store_mb", "value": "${_self}"} to 'blackboard'.
  2. Send {"text": "lookup_bank"} to ${_self}.
  3. Send {"text": "renew"} to 'keep_alive'.
  4. Return frames: ["@store-wait-bank"].

Otherwise: return frames: ["@store-wait-bank"].
@@end

@@store-wait-bank
You are looking for the bank. Message: ${_msg} from ${_msg_source}.

If ${_msg_source} is ${_self} and ${_msg} is "lookup_bank":
  Send {"action": "read", "key": "bank_mb"} to 'blackboard'.
  Send {"text": "renew"} to 'keep_alive'.
  Return frames: ["@store-wait-bank"].

If ${_msg_source} is "blackboard" and ${_msg} starts with "agent_":
  Send {"text": "balance_request", "reply_to": "${_self}"} to ${_msg}.
  Send {"text": "renew"} to 'keep_alive'.
  Return frames: ["@store-wait-balance"].

Otherwise:
  The bank is not registered yet, or this was just an acknowledgement.
  Send {"text": "lookup_bank"} to ${_self}.
  Send {"text": "renew"} to 'keep_alive'.
  Return frames: ["@store-wait-bank"].
@@end

@@store-wait-balance
Waiting for the bank reply. Message: ${_msg} from ${_msg_source}.

If ${_msg} starts with "balance:":
  Send {"action": "read", "key": "coordinator_mb"} to 'blackboard'.
  Send {"text": "renew"} to 'keep_alive'.
  Return frames: ["Balance result: ${_msg}\n@store-wait-coordinator"].

Otherwise: send {"text": "renew"} to 'keep_alive' and return frames: ["@store-wait-balance"].
@@end

@@store-wait-coordinator
The balance result is stored at the top of this frame as "Balance result:".
Message: ${_msg} from ${_msg_source}.

If ${_msg_source} is "blackboard" and ${_msg} starts with "agent_":
  Read the stored balance result from this frame.
  Send {"action": "write", "key": "marketplace_result", "value": "<that balance text>"} to 'blackboard'.
  Send {"text": "<that balance text>"} to ${_msg}.
  Terminate with empty frames [].

Otherwise: return frames: ["@0"].
Also send {"text": "renew"} to 'keep_alive' whenever continuing to wait.
@@end

@@wait-result
You are the coordinator. You already spawned the bank and store.
A message arrived as ${_msg} from ${_msg_source}.

If ${_msg} starts with "balance:":
  Send {"text": "Marketplace result: ${_msg}"} to 'human'.
  Terminate with empty frames [].

Otherwise:
  Ignore blackboard acknowledgements and unrelated messages.
  Send {"text": "renew"} to 'keep_alive'.
  Return frames: ["@wait-result"].
@@end

This is the first cycle (${_msg} is "init"). Do all of these steps:
1. Send {"action": "write", "key": "coordinator_mb", "value": "${_self}"} to 'blackboard'.
2. Send {"text": "Coordinator: spawning bank and store..."} to 'human'.
3. Spawn a child with frames: ["@bank-program"], dest "bank_id", "disown": true.
4. Spawn a child with frames: ["@store-program", "@store-wait-bank", "@store-wait-balance", "@store-wait-coordinator"], dest "store_id", "disown": true.
5. Send {"text": "renew"} to 'keep_alive'.
6. Return frames: ["@wait-result"].
